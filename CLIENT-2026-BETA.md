# Old Flurry 2026 optional 64-bit beta

Separate experimental x64 DirectX 12 client, custom desktop icon and setup script. Setup copies an existing legal Old Flurry installation to a new folder, preserves local settings/profiles, configures our public server, and enables multiple client windows.

Download the ZIP from [the beta prerelease](https://github.com/edgewoodnm/SWG-Old-Flurry-Assets/releases/tag/client-2026-beta-0.1.0), extract it completely, and run INSTALL-BETA.cmd. Read README.txt for requirements and known limitations. Windows 10 x64 remains unverified. God-buff in-game retest is pending. The normal launcher continues to use the classic client.

Includes current custom TRE resources through v1.0.34. No private configuration or account data is distributed.
